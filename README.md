# Laboratorio: Misconfigured Cloud Security (AWS S3)

## Descripción
Práctica orientada a demostrar los riesgos de una mala configuración (*misconfiguration*) en la nube de AWS (S3), simulando la exposición de credenciales y su posterior aseguramiento mediante políticas de bloqueo de acceso público y el principio de mínimo privilegio.

## Comandos Utilizados en el Laboratorio
Puedes revisar el archivo \script_laboratorio.ps1\ en este repositorio para ver la secuencia completa de comandos ejecutados en PowerShell junto con LocalStack y Docker.
